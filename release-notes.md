## [0.8.1](https://github.com/joryirving/LLMKube/compare/v0.9.1...v0.8.1) (2026-07-07)


###   BREAKING CHANGES

* **security:** gate local/hostPath model sources + block controller SSRF (GHSA-jw3m-8q7m-f35r) ([#981](https://github.com/joryirving/LLMKube/issues/981))
* **foreman:** Agent.spec.requestTimeoutSeconds changes meaning from a per-request HTTP timeout to a loop-wide wall-clock budget, and its default moves from 600 to 3600. The former per-request bound is now the new Agent.spec.requestTurnTimeoutSeconds (default 120). Re-apply your Agent CRs after upgrade so existing Agents pick up explicit values.
* update default CUDA image to server-cuda13 for Qwen3.5 and Blackwell support ([#262](https://github.com/joryirving/LLMKube/issues/262))
